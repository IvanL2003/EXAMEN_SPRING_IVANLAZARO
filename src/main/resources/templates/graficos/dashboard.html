Dashboard de Consultame

Graficos con datos reales

Doctores por Consultorio (Polar Area)
Polar Area: Similar al pie chart pero cada sector tiene el mismo angulo. El radio de cada sector representa el valor. Util para comparar magnitudes entre categorias sin que el angulo distraiga.
Doctores por Especialidad (Tarta)
Pie (Tarta): Divide un circulo en sectores proporcionales al valor de cada categoria. Ideal para mostrar la composicion porcentual de un total.

Graficos de ejemplo (datos estaticos)

Citas por mes (Bar / Barras)
Bar (Barras): Muestra barras verticales cuya altura representa el valor. Es el tipo mas comun para comparar cantidades entre categorias discretas (meses, productos, etc.). Se define con type: 'bar'.
Pacientes por especialidad (Bar Horizontal)
Bar Horizontal: Igual que el bar chart pero con barras horizontales. Se consigue con indexAxis: 'y' en las opciones. Util cuando las etiquetas del eje son textos largos.
Evolucion de citas (Line / Linea)
Line (Linea): Conecta puntos de datos con lineas rectas. Perfecto para mostrar tendencias a lo largo del tiempo. Se define con type: 'line'. Se puede rellenar el area bajo la linea con fill: true.
Estado de citas (Doughnut / Rosquilla)
Doughnut (Rosquilla): Identico al pie chart pero con un agujero en el centro. Se define con type: 'doughnut'. El hueco central se puede usar para mostrar un valor total o un icono.
Valoracion de doctores (Radar)
Radar: Muestra multiples variables en ejes que parten de un centro comun, formando un poligono. Se define con type: 'radar'. Ideal para comparar perfiles multidimensionales (habilidades, metricas de rendimiento).
Edad vs Numero de citas (Scatter / Dispersion)
Scatter (Dispersion): Muestra puntos individuales en un plano X-Y. Se define con type: 'scatter'. Cada dato es un objeto {x, y}. Util para detectar correlaciones entre dos variables numericas.
Consultorios: capacidad y ocupacion (Bubble / Burbuja)
Bubble (Burbuja): Extension del scatter donde cada punto tiene un tercer valor representado por el radio de la burbuja. Se define con type: 'bubble'. Cada dato es {x, y, r}. Permite visualizar tres dimensiones en un plano 2D.
Citas por turno y mes (Bar Apilado / Stacked)
Stacked Bar (Barras apiladas): Variante del bar chart donde las barras de distintos datasets se apilan una encima de otra. Se activa con scales: { x: { stacked: true }, y: { stacked: true } }. Muestra el total y la composicion de cada categoria a la vez.
